# 栖读 · 私人阅读书房 v0.2

可独立部署的手机/电脑网页阅读器，支持 TXT、EPUB、PDF。本机预览和服务端 API 已实测；Render 部署配置已提供。**当前不是公网网站，夸克网盘也尚未接入。**

## 先看效果

项目已在本机运行：<http://localhost:4180>。登录页可点“浏览示例书房”，也可输入本机口令进入真正的私人服务端书架。口令只在本机生成，路径为 `.data/local-access.txt`；不要把这个文件发给别人。

- 电脑：同一链接打开即可。
- 手机：目前本机预览仅在电脑本地；要从手机访问需要同 Wi-Fi 的 LAN 地址，或先部署公网服务。真正部署后，手机和电脑使用相同 HTTPS 网址，不要求处在同一个 Wi-Fi。
- 启动/停止：双击 `打开栖读.cmd`，关闭启动窗口即可停止。

## 这版能做什么

- 私人书房口令登录（scrypt 校验、HttpOnly/SameSite 会话 Cookie、CSRF 校验、登录限速）。这是**栖读访问口令**，不是夸克账号。
- TXT、EPUB、PDF 上传到栖读自己的服务端，三类阅读器均使用真实文件。
- 服务端保存书籍、阅读位置、收藏、阅读时长和书签；新设备登录同一服务后可刷新书架继续阅读。
- 云端更改用版本号检测并发冲突；当前没有云端删除接口，避免误删。
- 单本最大 100 MB，书库合计最大 500 MB。
- 夸克页明确标为“尚未接入”；不收夸克密码/Cookie，不展示假二维码。

## 部署到公网

仓库包含 `Dockerfile`、`render.yaml` 和 `DEPLOY.md`。Render Blueprint 会创建**付费 Starter Web Service 和 1 GB 持久磁盘**，请在 Render 页面先检查当时价格和付款方式。没有创建云资源，也没有自动上传代码。详细操作、环境变量和安全限制见 [DEPLOY.md](DEPLOY.md)。

最低要求：把代码放入你自己的 GitHub 仓库，在 Render 连接该仓库并应用 Blueprint；在部署控制台设置专用的 `QIDU_ACCESS_PASSWORD`（12–256 字符），等待构建完成，再用 Render 提供的 HTTPS 域名访问。若使用自定义域名，在 Render 环境变量设置 `APP_ORIGIN`。不要把口令提交进仓库。

在 Render 连接/GitHub 仓库/启用付费服务前，必须使用你自己的账户并自行确认费用。代码已准备，**没有你的云平台授权就无法代你创建或付款**。

## 本机开发与测试

需要 Node.js >=24.13、pnpm。首次安装依赖后：

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm start
pnpm test
pnpm test:browser
pnpm test:cloud
```

`pnpm start` 默认监听 `127.0.0.1:4180`。本机口令首次启动时生成在 `.data/local-access.txt`；私人书籍与 SQLite 数据保存在 `.data/`。请勿将 `.data/` 加入版本控制。

## 已知限制

- 尚未实现夸克 OAuth/扫码授权、网盘目录浏览、网盘文件流读取。
- 当前是单入口共享口令，不是多用户账号体系。知道口令的人均可访问书库；使用独有强口令。
- 需要云端并发修改时刷新书架；检测到版本冲突会拒绝静默覆盖。
- 示例书是原创演示资料，不代表用户网盘内容。
- Render 持久盘和服务均为付费服务；需自行确认账单。定期通过平台维护/快照功能备份书库数据。
